# Home Inventory Client
This app is used to track the quantity of food items and products currently in a household, as well as generating a shopping list 
based on the current, minimum, and maximum quantities. Users can manage their shelves, add, update, and remove items from the inventory listing, and manage the quantity of items by scanning them into or removing them from shelves.

In order to use this app, you must also have the Home Inventory server hosted either on a local or remote server.
